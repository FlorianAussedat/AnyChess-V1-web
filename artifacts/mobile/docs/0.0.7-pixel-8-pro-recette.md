# AnyChess 0.0.7 — Recette Pixel 8 Pro

**Protocole préparé, non exécuté dans Codex.** Utiliser AnyChess Dev installé, code de la branche PR 07 et un serveur Expo accessible. Aucun ordinateur nécessaire pour les gestes ci-dessous si le serveur est déjà disponible. Un serveur/tunnel Cloud n'est pas garanti après fin de tâche ; noter branche/commit réellement servis avant tout résultat. L'export JS automatisé ne prouve ni présence des modules natifs ni réception d'e-mails.

## Préparation et règles

- Comptes de démonstration A et B ; second appareil ou session Web de démonstration avec A pour E. Compte jetable D **distinct** pour suppression.
- Corpus de démonstration P : deux PGN contenant chacun plusieurs parties ; un PGN avec commentaires, variantes/sous-variantes, NAG et position initiale FEN ; fichiers vide, invalide et trop volumineux ; une FEN à roques/trait spécifiques. Conserver les originaux dans Téléchargements et une copie indépendante. Préparer aussi un fichier Drive disponible hors ligne.
- Deux photos de test portrait/paysage avec repères aux coins, photo EXIF tournée et PNG transparent ; aucune photo privée nécessaire.
- Avant E/F : exporter les PGN de démonstration et vérifier leur réimport dans une autre app. Ne jamais utiliser la seule copie d'une bibliothèque personnelle. Noter les identifiants/titres et coups attendus de chaque compte.
- Chaque ligne doit recevoir : réussi/échoué/non exécuté, date, branche/commit, capture éventuelle **sans secret**. Un échec de perte/fuite de données arrête la recette ; conserver l'état et les sauvegardes, ne pas réinitialiser.
- Gravités : **B** bloquant, **I** important, **C** cosmétique. Les scénarios ci-dessous sont tous des **validations manuelles nécessaires**. « Local » signifie sans service distant intrinsèque ; le chargement initial Expo nécessite toujours l'accès au serveur si son bundle n'est pas déjà disponible.
