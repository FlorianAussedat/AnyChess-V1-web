## Cause identifiée

Sur Preview (Pixel 8 Pro), le premier téléchargement du modèle FR semblait se terminer, puis la dictée restait inutilisable et chaque nouvelle tentative restait à 0 %.

Causes confirmées dans le code (pas seulement des pistes) :

1. **Marqueur READY uniquement après `load` réussi** — si l’archive était décompressée mais le chargement natif échouait (ou n’était pas atteint), `status` renvoyait `missing`. L’UI proposait un nouveau téléchargement au lieu d’une réparation locale.
2. **Pas d’état `unpacked`** — les fichiers déjà présents sans READY étaient traités comme absents → re-téléchargement inutile, souvent bloqué.
3. **Flicker réseau `unknown`** — Expo Network peut quitter brièvement `WIFI` ; l’ancien flux **mettait en pause** un téléchargement déjà accepté, ce qui laissait la barre à 0 % sans erreur.
4. **Échecs de lancement du téléchargement natif non remontés** — une exception au `download(...)` pouvait laisser la session en `downloading` sans progression.
5. **Pas d’identifiant de transfert** — les événements tardifs d’une tentative précédente pouvaient être appliqués à la suivante.

## Corrections

| Zone | Changement |
| --- | --- |
| Natif `VoskAsrModule.kt` | `status` → `installed` \| `unpacked` \| `missing` ; `transferId` sur download/progress/done ; zip conservé jusqu’au `load` réussi ; READY écrit seulement après load |
| `offlineModelFlow.ts` | Offre de réparation (`repairOnly`) ; phases `verifying` / `installing` / `preparing` / `ready` ; `unknown` ne pause plus un transfert accepté ; `formatMegabytesOnly` |
| `offlineModelSession.ts` | `transferId` ; try/catch sur lancement ; chemin `prepare` sans re-download ; watchdog annulable ; ignore événements d’un autre transfert |
| `androidDictation.ts` | Lecture `unpacked` ; `startVoskDownload` rétrocompatible 3/4 args ; injection tests |
| `OfflineModelBanner.tsx` | `AppButton` primary orange ; tailles en Mo uniquement ; barre + % ; étapes distinctes ; confirmation prêt |
| i18n FR/EN | Clés repair / verifying / installing / preparing / ready / failedLoad |
