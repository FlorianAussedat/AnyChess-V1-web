### Procédure pour débloquer Preview (et optionnellement Dev via EAS)

1. Sur [expo.dev](https://expo.dev) → Account → Access tokens : créer un jeton avec accès au projet `@anychess/anychess`.
2. Dans Cursor → Secrets de l’environnement Cloud Agent : ajouter `EXPO_TOKEN` (ne pas coller le jeton dans le chat).
3. Vérifier Credentials → Android → `com.anychess.preview` : **réutiliser** la clé existante (noter son SHA-256).
4. Relancer l’agent / suivre avec :

```bash
cd artifacts/mobile
git checkout f5c718bbcacbb73bbaa2a14509a855dfef3aada4
pnpm exec eas whoami   # doit afficher le compte anychess
pnpm exec eas build -p android --profile preview --non-interactive
```

5. Télécharger l’APK depuis la page du build EAS ; vérifier `apksigner verify --print-certs` contre l’empreinte Preview déjà installée sur le Pixel avant d’installer.
